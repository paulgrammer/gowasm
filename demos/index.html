gowasm demos

Each page below is Go, compiled to WebAssembly, running in this tab with no server involved. They exist because a passing test suite does not show you anything: these do. The first few are the point of the tool — each is something JavaScript either does worse or cannot do at all.

Things JavaScript cannot do

Regex that cannot hang

Race V8's backtracking engine against Go's RE2 on the same evil input.

CUE validation

A configuration language with no JavaScript implementation at all.

Exact money

0.1 + 0.2, and integers past 253, without losing anything.

Unicode

Count and truncate by grapheme; transliterate; slugs that survive CJK.

Things that normally need a server

PDF toolkit

Create, merge, watermark and encrypt. Nothing is uploaded anywhere.

Spreadsheets

Build a real .xlsx with formulas, and read one back.

Git

A real repository in memory: commits, branches, diffs, patches.

HTML sanitizing

Allowlist cleaning with no DOM and no jsdom.

Image processing

Blur, edges, tone and histograms, with no canvas round trip.

QR codes

Watch error correction cost space as you raise the recovery level.

Developer tools

gofmt

Go's own parser and formatter, with no Playground round trip.

Syntax highlighting

297 languages compiled in, with no per-language grammar fetch.

Expression rules

Evaluate user-written rules without going near eval.

URL extraction

The smallest example, and the one the README opens with.

Because they are fun

Chess

Full legality, in Go. The board only draws what Go says is true.

CHIP-8

An emulator whose framebuffer arrives as a Uint8Array.

Binary

Gzip and hash a file you drop in, without it leaving the page.
