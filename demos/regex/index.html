Regular expressions that cannot be made to hang

JavaScript's regex engine backtracks, so some patterns take exponential time on inputs an attacker can choose. Go's is RE2 and runs in time linear in the input, whatever the pattern. Both run below, in this tab, on the same input.

Pattern and input

Start low and increase. Each extra a roughly doubles the work V8 does. Above about 30 the page will freeze for a long time, because a backtracking match cannot be interrupted — that is the whole problem.
