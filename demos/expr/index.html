User-written rules, without eval

Letting users write a condition usually means eval or new Function, which hands whoever wrote the string everything the page can do. This is a small expression language: no I/O, no unbounded loops, and no reach beyond the data you pass in. Type errors are caught when the rule is compiled, not when it runs.
